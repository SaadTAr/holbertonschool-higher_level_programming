# SQL - More queries

This project is part of the Holberton School Higher Level Programming curriculum.

## Description

The project focuses on advanced SQL concepts including:

- User privileges
- Creating users
- Granting permissions
- Table constraints
- UNIQUE constraints
- PRIMARY KEY
- FOREIGN KEY
- Joins
- Subqueries

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0
- SQL scripts end with a new line
- SQL keywords are written in uppercase
- Each script starts with a comment describing its purpose
