# JavaScript - Warm up

This project introduces the basics of JavaScript programming using Node.js.

## Learning Objectives

By the end of this project, I should be able to explain:

- Why JavaScript programming is useful
- How to run a JavaScript script
- How to create variables and constants
- The differences between `var`, `let`, and `const`
- JavaScript data types
- How to use `console.log`
- How to access command-line arguments using `process.argv`
- How to use conditional statements
- How to concatenate strings
- How to write simple JavaScript programs

## Files

- `0-javascript_is_amazing.js` - Prints `JavaScript is amazing`
- `1-multi_languages.js` - Prints three programming language messages
- `2-arguments.js` - Prints a message depending on the number of arguments
- `3-value_argument.js` - Prints the first argument passed to the script
- `4-concat.js` - Prints two arguments in a sentence

## Requirements

- JavaScript files are executed using Node.js
- Code follows the project style requirements
- `console.log` is used to display output
- `var` is not used where prohibited
